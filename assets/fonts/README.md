# Шрифт подписей графиков

DejaVu Sans включён для одинакового отображения кириллицы, греческих букв и математических обозначений в Windows/Linux. Источник файла — пакет DejaVu Sans дистрибутива Debian. Условия распространения находятся в LICENSE.txt; шрифт распространяется вместе с программой без изменения.
