# Эмблемы факультетов МГУ и фотографии авторов

`vmk-logo.png` — оригинальное изображение, загруженное автором проекта через GitHub. Эмблемы используются на титульной странице и странице авторов; хранятся в репозитории и не требуют доступа к внешнему сайту.

Размер исходного файла: 236 × 249 пикселей. Изображение отображается с сохранением пропорций.

Ссылки на изображения, предоставленные автором:
- https://conf.msu.ru/media/cache/event_logo_big/file/event/4645/rus_logo_d78460b200ea94d48a8f76e2d753665bba6853d7.png
- https://bookonlime.ru/sites/default/files/styles/faculty-list/public/taxonomy/university/vmk_mgu.jpg?itok=Smq38Cl7

`physics-logo.png` — синяя эмблема физического факультета, 1024 × 1024 пикселя.
Исходный PNG сохранён без изменений из открытого проекта Профкома студентов физфака МГУ:
https://github.com/profcomff/webapp-ui/blob/main/src/public/icons/icon_1024x1024.png

Исходный проект распространяется по BSD 3-Clause; текст сохранён в
`physics-logo-LICENSE.txt` и включён в переносимую сборку. Сведения о символике
факультета: https://www.phys.msu.ru/rus/gallery/symbolics/

`presentation.py` создаёт уменьшенные изображения для интерфейса, сохраняя
пропорции и прозрачность. В готовую сборку входят обе эмблемы и лицензия;
интернет для показа не требуется.

`photo_stas.jpg` и `photo_eva.jpg` — фотографии Станислава Капитонова и Евгении Корж, предоставленные пользователем для страницы авторов. Они включены в переносимую сборку. Оригинальные файлы сохранены без изменений; интерфейс учитывает ориентацию EXIF и показывает центральный квадратный фрагмент с сохранением пропорций. Лицензия BSD выше относится к заимствованному ресурсу эмблемы физфака, а не к фотографиям авторов.
