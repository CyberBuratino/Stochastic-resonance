# Соответствие требованиям задания

Основа: документ «Требования.doc», заметки преподавателя и §12.6 конспекта О. А. Чичигиной. Последующие уточнения пользователя определяют текущий состав приложения.

| Требование | Текущая реализация |
|---|---|
| Windows и Linux, минимум действий для запуска | Переносимая папка PyInstaller для каждой ОС. В Windows запускается StochasticResonance.exe без BAT и установки Python; вся папка с _internal сохраняется. |
| Возможность изменять оформление на Python | Модули модели, графики, оформления, переводов и интерфейса разделены; инструкция в EDITING.md. |
| Титульная страница | Эмблемы физфака и ВМК в углах, название МГУ и факультета сверху по центру, курс и название проекта по центру; меню с RU/EN под «Выходом» без верхней панели. |
| Постоянная навигация | В демонстрации, теории и авторах — верхняя шапка с переходами и RU/EN. На титульной странице — собственное меню и язык под «Выходом». Смена языка сохраняет размеры графиков. |
| Авторские сведения | Две равные карточки: Капитонов Станислав и Корж Евгения. Лектор — Григорьев Кирилл Сергеевич, руководитель — Чичигина Ольга Александровна. Показаны фотографии из photo_stas.jpg и photo_eva.jpg; фотографии и эмблемы локальные. |
| Анимация и синхронные графики | Частица на дорожке под потенциалом; текущий конец траектории отмечен маркером. В вертикальном положении они совмещены по x и соединены коротким пунктиром; при повороте остаётся маркер. Заголовок траектории и поворот вынесены в фиксированную боковую панель. |
| Оси и масштабы | Численные деления, обозначения x, t, Ueff, F; все величины безразмерные, дополнительные подписи [1] удалены. |
| Изменяемые параметры | T, a, b, f, ω, γ; поле seed удалено, внутреннее зерно сохраняет воспроизводимость. Названия параметров показаны шрифтом 16 pt; буквы a/b скрыты, видны «Барьер» и «Глубина ям». Числа продолжают задавать коэффициенты, а сама глубина равна a²/(4b). |
| Температура и шум | Связь D=γT сохранена в модели; поясняющая строка D в панели удалена. |
| Старт, пауза, стоп, два темпа | При запуске виден главный экран; при переходе в демонстрацию расчёт начинается автоматически, исходный темп ×1. Крупные кнопки закреплены сверху; темп показа не меняет шаг интегрирования. |
| Восстановление режима резонанса | Одна кнопка отменяет отложенное применение ползунков, восстанавливает весь показательный набор и начинает расчёт заново без перезапуска программы. |
| Прокручиваемая боковая панель | Прокрутка параметров не сдвигает графики; подсказки о прокрутке и сбросе удалены. |
| Выбор окраски | По величинам, по сторонам барьера и чёрно-белая схема; надписи x < 0 / x ≥ 0 удалены, состояние частицы не меняется. |
| Поворот графика | Координата и сила поворачиваются вместе; данные сохраняются. Поясняющая строка о направлении осей удалена. |
| Экспорт | Все функции и элементы CSV/SVG-экспорта удалены по запросу от 28 октября. |
| Теория | На странице только TODO в обоих языках; модель и источники описаны в README. |
| Стационарный потенциал | Нейтральный пунктир U(x) и сплошной Ueff(x,t) на общей шкале; совпадают при нулевой внешней силе. |
| Отрисовка | AGG/aggdraw в экранном разрешении, буфер Pillow, локальный шрифт; без фильтрации истории. |
| Окно времени | Выбор 3 или 6 периодов, по умолчанию 3. Сохраняются последние 6 периодов для расширения на паузе без сброса; нет вымышленных точек до начала расчёта. |
| Разные размеры окна и проектор | Изменяемый размер окна, масштабирование графиков, прокрутка длинной панели, жирные заголовки. Нужна приёмка на целевой машине. |

## Уточнения состава программы

5 октября удалены отдельный график отклика по температурам и связанный интерфейс. Они не возвращались при переносе на Python.

21 октября приложение перенесено на Python, добавлены независимая прокрутка параметров и выбираемые принципы окраски. Руководство по изменениям оформления — [EDITING.md](EDITING.md).

28 октября удалены все функции CSV/SVG-экспорта, подсказки панели об интенсивности шума, барьере, прокрутке и сбросе, пояснения направления осей и обозначения [1]. Теория заменена на TODO. Заголовки выделены жирным; постоянная шапка и размеры графиков сохраняются при RU/EN. Экранная отрисовка использует покрытие пикселей AGG в исходном разрешении. Временное окно сохраняет постоянную длину и не растягивает историю на старте.

4 ноября увеличены надписи на кнопках, демонстрация запускается автоматически. Управление расчётом и новый режим резонанса закреплены над прокруткой. Убрано поле зерна, уточнены подписи a/b. После оценки нагрузки и согласия пользователя добавлен выбор 3/6 периодов. Переносимая Windows-сборка по-прежнему содержит Python и запускается непосредственно через .exe.

Сборки создаются отдельно для Windows и Linux. Упаковка не подтверждает совместимость со всеми историческими версиями ОС; требуется проверка компьютера преподавателя и проектора.

Уточнение 4 ноября: при открытии программы остаётся главный экран. Автоматический запуск выполняется при переходе в демонстрацию; исходный темп и темп кнопки резонанса — ×1. Возвращение в раздел не сбрасывает накопленную траекторию.

6 ноября названия параметров увеличены до 16 pt, буквы a/b и подписи сторон барьера убраны. Частица перенесена под потенциал ближе к текущему концу траектории, добавлена связь пунктиром в вертикальном положении. Заголовок траектории и поворот вынесены в фиксированную боковую панель. Нейтральный пунктир стационарного потенциала показывает опору для наклоняющегося мгновенного потенциала. Уравнения и интегратор не менялись.

8 ноября титульная страница и авторы приведены к предоставленным образцам: центрированная академическая шапка с двумя эмблемами, две карточки с плейсхолдерами и именами авторов, лектор и руководитель из образцов. Общая навигация и RU/EN видны также на главной странице.

Уточнение 8 ноября: верхняя панель убрана с титульника, переключатель языка перенесён под «Выход». На других страницах панель остаётся. Увеличены меню, поля чисел и шкалы графиков. Плейсхолдеры заменены присланными фотографиями, которые также включены в готовую сборку.
