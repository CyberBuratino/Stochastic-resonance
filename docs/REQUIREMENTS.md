# Соответствие требованиям задания

Основа: документ «Требования.doc», заметки преподавателя и §12.6 конспекта О. А. Чичигиной. Уточнения пользователя из переписки определяют текущий состав приложения.

| Требование | Реализация |
|---|---|
| Windows и Linux, минимум действий для запуска | Переносимая папка PyInstaller для каждой ОС; после полной распаковки запускается исполняемый файл. Python и библиотеки включены в сборку. |
| Возможность изучать и изменять программу на Python | Исходники Python 3.11+; Tkinter из стандартной библиотеки; отдельные модули модели, графики, оформления, переводов и интерфейса. |
| Титульная страница | Название, рисунок потенциала без подписей, переходы к демонстрации, теории и авторам, переключение языка. |
| Авторские сведения | Капитонов Станислав, Корж Евгения, ВМК МГУ; преподаватель Чичигина Ольга Александровна; локальный логотип ВМК. Настоящие фотографии ещё не предоставлены. |
| Анимация и синхронные графики | Частица на горизонтальной прямой, проекция к мгновенному потенциалу; координата и внешняя сила на общей временной шкале. |
| Подписанные оси и масштабы | Численные деления, безразмерные величины; отдельная шкала внешней силы. |
| Изменяемые параметры | T, a, b, f, ω, γ и seed; физически некорректные сочетания отклоняются. |
| Температура связана с тепловым шумом | D=γT при массе и постоянной Больцмана, равных единице. |
| Старт, пауза, стоп, медленный и быстрый показ | Изменение темпа показа не меняет шаг интегрирования. |
| Прокручиваемая боковая панель | Параметры прокручиваются внутри собственного контейнера; графики остаются в соседней неподвижной области. |
| Выбор принципа окраски | По физическим величинам, по состоянию частицы, чёрно-белая схема. |
| Возможность цитировать изображения | Векторный SVG-экспорт с текущей схемой; в чёрно-белой схеме используются разные начертания линий. |
| Экспорт данных | CSV траектории и параметров. |
| Поворот графика | Координата и сила поворачиваются вместе; данные и состояние частицы сохраняются. |
| Теория и источники | Краткая теория на RU/EN до уравнений движения включительно; библиография в README. |
| Проектор и разные размеры окна | Изменяемый размер окна, масштабирование графиков, отдельная прокрутка длинной панели. Приёмка на реальном компьютере и проекторе остаётся необходимой. |

## Уточнения состава программы

По запросу от 5 октября отдельный график отклика по температурам и весь его интерфейс удалены. Они не возвращаются при переносе на Python. Теория в приложении заканчивается уравнениями движения и пояснением мгновенного потенциала.

По запросу от 21 октября приложение переписано на Python, параметры получили отдельную прокрутку, добавлены выбираемые принципы окраски и чёрно-белый режим. Для человека, меняющего оформление, подготовлено [docs/EDITING.md](EDITING.md).

Сборки создаются в CI отдельно для Windows и Linux. Успешная упаковка не подтверждает совместимость со всеми историческими версиями Windows или Linux; требуется проверка целевой машины преподавателя.
