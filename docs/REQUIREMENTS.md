# Соответствие материалам задания

Источники требований: приложенный документ «Требования.doc», фотография заметок от 14.09.2026, скриншот §12.6 конспекта О. А. Чичигиной. Приложения рассматриваются как материалы задания; их содержание не является самостоятельным поручением отправлять сообщения, письма или менять чужие данные.

| Требование | Реализация / статус |
|---|---|
| Минимум действий для запуска, без установки библиотек | Распаковать и открыть index.html; также BAT/SH. Современный браузер нужен. |
| Желательно EXE; ранние Windows возможны | EXE не включён, старые Windows не проверены. Браузерный вариант выбран для Windows/Linux без устанавливаемых библиотек. |
| Титульная страница и кнопки презентации, теории, авторов, выхода | Есть; выход останавливает расчёт и предлагает закрыть вкладку. |
| Эмблемы факультетов | Официальное изображение не предоставлено; вместо него текстовое обозначение ВМК МГУ. Нужно дополнить. |
| Имена и фотографии авторов, руководитель | Имена и руководитель указаны по сообщению пользователя; фотографии ещё нужны. |
| Визуализация физического процесса и синхронные графики | Частица над потенциалом, пунктирная проекция, координата и сила; поворот графиков на 90° с общей координатной шкалой. |
| Оси, размерности, масштабные линейки | Подписанные оси с делениями; безразмерные единицы [1]; координата и сила имеют отдельные шкалы. |
| Интерактивные параметры, ограничения | T, a, b, f, ω, γ, seed; диапазоны и валидация; физическая модель проверяет вход. |
| Старт, пауза, стоп; медленный и быстрый режим | Есть. Темп показа не влияет на Δt. |
| Теория, инструкции, источники | Раздел в приложении на RU/EN и README; формулы в MathML. |
| Разные разрешения и проектор | Адаптивная вёрстка, контраст, масштабирование canvas. Проверка реальным проектором остаётся обязательной. |
| Windows/Linux без библиотек | Автономные HTML/CSS/JS без внешних зависимостей; браузерная проверка в Chromium/Linux через локальный HTTP (file:// заблокирован политикой облачного браузера). Нативная проверка Windows ещё не выполнена. |
| Переключение на английский | Все страницы, управление, теория, результаты и сообщения. |
| Показ стохастического резонанса | Реальный расчёт отклика по ансамблю, погрешности, CSV, отмена измерения. |

Промежуточные этапы из фотографии: через 3 недели после 14 сентября — рабочая анимация; начало ноября — показ аудитории; до декабря — окончательная доработка; теория ближе к концу. Это план учебной сдачи, не автоматические напоминания. Готовность на компьютере преподавателя и проекторе нельзя подтвердить проверкой в облачной среде.
