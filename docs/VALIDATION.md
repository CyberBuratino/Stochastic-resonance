## Модель и геометрия

```sh
python -m unittest discover -s tests -v
```

Проверяются минимумы, барьер, сила как производная потенциала, нормировка шума D=γT, воспроизводимость, выключение силы и допустимые параметры. Для численного эталона используются траектории исходной модели; приложение выполняет Python-код.

Отдельно проверяются неизменность данных при смене палитры, повороте и выборе окна, наличие всех сохранённых точек, отдельная аналитическая линия силы и корректные оси. При выбранных 3 или 6 периодах длина окна постоянна, не зависит от объёма уже накопленной истории и не создаёт точек до начала расчёта. Буфер ограничен последними 6 периодами. Деления привязаны к абсолютным моментам времени и смещаются вместе с окном.

Готовый пример: a=1, b=0,5, T=0,35, f=0,24, ω=0,08, γ=1, Δt=0,02, внутреннее зерно 42. Тест сравнивает амплитуду первой гармоники стороны ямы sign(x) с низкой (0,025) и высокой (1,1) температурой. После двух периодов разгона за 12 периодов наблюдения получены амплитуды около 0,715, 0 и 0,100 соответственно. Это проверка показательного воспроизводимого режима, а не поиск универсального оптимума. Диагностический график отклика в интерфейс не возвращается.

## Экранная отрисовка

Линии рисуются через aggdraw 1.3.19 с покрытием пикселей AGG в исходном экранном разрешении. Pillow 12.0.0 хранит кадр и отображает локальный шрифт. Настройка GRAPH_SUPERSAMPLING по умолчанию равна 1; в обычном режиме нет уменьшения кадра фильтром Lanczos.

При отсутствии aggdraw или ошибке загрузки его нативной библиотеки применяется резервная отрисовка Pillow с разрешением не ниже 4× и уменьшением Lanczos. Проверки воспроизводят обе ошибки импорта в свежем процессе Python. Отдельный тест запускает `main.py` без aggdraw и проверяет непустые изображения стартовой иллюстрации и двух графиков; тест интерфейса также проверяет обновление траектории, поворот, язык и чёрно-белую схему в резервном режиме.

Нужны проверки сглаженных краёв, кириллицы, пунктира чёрно-белой схемы, постоянного изображения Canvas без очистки между кадрами и сохранения исходной траектории. Субъективную плавность движения нужно оценивать на последовательности кадров, а не по одному скриншоту. Отдельно проверяются стартовый пустой участок временного окна и движение абсолютных делений без растяжения старых данных.

## Интерфейс

Tkinter требует графический сеанс. Пропуск тестов интерфейса из-за отсутствия дисплея не подтверждает исправность окна.

Linux с виртуальным экраном:

```sh
STOCHLAB_GUI_TESTS=1 xvfb-run -a python -m unittest discover -s tests -v
```

Windows PowerShell:

```powershell
$env:STOCHLAB_GUI_TESTS = "1"
python -m unittest discover -s tests -v
```

Проверяются прокрутка панели без смещения графиков, колёсико над нужной областью, клавиатурная навигация, старт/пауза/стоп, поворот, палитры, RU/EN, авторы и маленькое окно. На обоих языках дополнительно проверяются постоянные навигационные кнопки, стабильные размеры графиков, TODO и отсутствие экспортных кнопок и удалённых пояснений.

## Упакованное приложение

```sh
python -m pip install -r requirements-build.txt
python -m PyInstaller --clean --noconfirm stochastic_resonance.spec
```

CI создаёт папки для Windows и Ubuntu 22.04. `--smoke-test` проверяет включённые ресурсы и зависимости без окна; `--smoke-test-gui` проверяет главный экран при запуске и автоматическое начало расчёта на ×1 после перехода, стартовую иллюстрацию и оба графика через мост Pillow—Tk, включая количество непустых пикселей в показанном PhotoImage. В готовую сборку должны войти aggdraw, Pillow, логотип и шрифт. Пользователь готовой сборки запускает `.exe` без BAT-файла и не устанавливает Python или библиотеки отдельно.

## Оценка увеличенного окна

Предварительный локальный замер при минимальной частоте ω=0,02, шаге Δt=0,02, одной точке на 5 шагов, размерах графиков 850×250 и 850×350: 3 периода содержат около 9 425 точек, 6 — 18 850. Медиана подготовки пары сцен и растеризации после прогрева: AGG около 44 и 67 мс; резервный Pillow — 174 и 227 мс. Замер относится к этому Linux-окружению, без стоимости передачи PhotoImage в Tk; на компьютере защиты время может отличаться. Увеличение окна сохраняет все точки, повышая нагрузку; исходный выбор 3 периода оставлен по умолчанию. Выбор 6 периодов добавлен после согласия пользователя.
