# Проверка Python-версии

Этот файл описывает способы проверки новой версии. Фактические результаты текущего pull request нужно сверять с GitHub Actions и отчётом о выполнении; до запуска проверок нельзя считать сборку или интерфейс подтверждёнными.

## Фактическая локальная проверка, 21 октября 2026

- Все 29 тестов прошли: 13 модели, 6 графики/SVG и 10 интерфейса Tkinter.
- Три эталонные траектории после 1000 шагов совпадают с JavaScript-версией до 10 знаков.
- Интерфейс проверен в Linux на виртуальном X-сервере со стандартным Tk 8.6 и Python 3.13: прокрутка панели не меняет положение графиков; колёсико вне панели её не прокручивает; Tab открывает нижнее поле; смена схемы и поворот не меняют траекторию.
- Проверены размеры окна 1240×880 и 900×650, кириллица, RU/EN, теория, логотип, параметры и ошибки ввода, старт/пауза/стоп, CSV и SVG.
- PyInstaller 6.16.0 создал Linux-папку; прошли проверка `--smoke-test` и полноценное открытие графического окна.
- Windows/Linux сборки в GitHub Actions проверяются отдельно; результаты относятся к соответствующему SHA и доступны в PR. Локальная Linux-сборка не подтверждает запуск Windows.

## Модель и графика

```sh
python -m unittest discover -s tests -v
```

Тесты модели должны проверять положения минимумов, высоту барьера, связь силы с производной потенциала, нормировку шума D=γT, воспроизводимость, выключение силы, устойчивость и запрещённые параметры. При переносе используется исходная JavaScript-модель как численный эталон, но приложение запускает Python-код.

Графика проверяется отдельно от модели: схема оформления не должна изменять состояние частицы, SVG должен быть корректным XML и сохранять подписи и начертания линий. Монохромная схема должна оставаться понятной без цветной печати.

## Интерфейс

Для тестов Tkinter нужен доступный графический сеанс. При запуске исходников без дисплея тесты интерфейса могут быть пропущены; такой результат не подтверждает исправность окна.

Linux с виртуальным экраном:

```sh
STOCHLAB_GUI_TESTS=1 xvfb-run -a python -m unittest discover -s tests -v
```

Windows PowerShell:

```powershell
$env:STOCHLAB_GUI_TESTS = "1"
python -m unittest discover -s tests -v
```

Проверяются независимая прокрутка панели, постоянное положение графиков при прокрутке, старт/пауза/стоп, поворот, смена схемы, RU/EN, теория, авторы, экспорт и небольшое окно. Настройка `STOCHLAB_GUI_TESTS=1` включена в CI; Linux-тесты выполняются через `xvfb-run`.

## Упакованное приложение

```sh
python -m pip install -r requirements-build.txt
python -m PyInstaller --clean --noconfirm stochastic_resonance.spec
```

CI создаёт переносимые папки для Windows и Ubuntu 22.04. После сборки исполняемый файл запускается с `--smoke-test`, который проверяет импорт Tkinter и доступность включённого логотипа без открытия окна. Это позволяет обнаружить пропущенные файлы и ошибки упаковки, но не заменяет проверку полноценного графического запуска.

Затем нужно вручную проверить запуск из полностью распакованного артефакта, подписи и графики, сохранение SVG/CSV и отображение логотипа. На Linux исполняемому файлу может потребоваться `chmod +x` после скачивания артефакта.

## Приёмка в аудитории

Финальная проверка включает компьютер преподавателя и проектор: запуск без установки Python, читаемость самых мелких надписей, доступность нижних настроек прокруткой и различимость сплошной и пунктирной линий в чёрно-белом режиме.
