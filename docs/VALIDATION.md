# Проверка текущей Python-версии

## Обновление 28 октября 2026

Локальные проверки текущего обновления выполнены; результаты приведены ниже. Статус сборок Windows/Linux связан с SHA коммита и публикуется в GitHub Actions и описании pull request. Результаты предыдущих версий сами по себе не подтверждают это обновление.

Проверяемый состав: независимая прокрутка параметров, три схемы окраски, поворот, старт/пауза/стоп, анимация и два графика. Экспорт CSV/SVG полностью удалён. Теория должна содержать ровно TODO в обоих языках. В панели и под графиками не должно быть удалённых поясняющих строк; оси подписаны x, t, Ueff, F, без [1]. Заголовки — жирные. Переключение RU/EN должно сохранять геометрию постоянной шапки и графиков.

## Модель и геометрия

```sh
python -m unittest discover -s tests -v
```

Проверяются минимумы, барьер, сила как производная потенциала, нормировка шума D=γT, воспроизводимость, выключение силы и допустимые параметры. Для численного эталона используются траектории исходной модели; приложение выполняет Python-код.

Отдельно проверяются неизменность данных при смене палитры и повороте, наличие всех сохранённых точек, отдельная аналитическая линия силы и корректные оси. Окно времени имеет постоянную длину в три периода, не зависит от объёма уже накопленной истории и не создаёт точек до начала расчёта. Деления привязаны к абсолютным моментам времени и смещаются вместе с окном.

## Экранная отрисовка

Линии рисуются через aggdraw 1.3.19 с покрытием пикселей AGG в исходном экранном разрешении. Pillow 12.0.0 хранит кадр и отображает локальный шрифт. Настройка GRAPH_SUPERSAMPLING по умолчанию равна 1; в обычном режиме нет уменьшения кадра фильтром Lanczos.

При отсутствии aggdraw или ошибке загрузки его нативной библиотеки применяется резервная отрисовка Pillow с разрешением не ниже 4× и уменьшением Lanczos. Проверки воспроизводят обе ошибки импорта в свежем процессе Python. Отдельный тест запускает `main.py` без aggdraw и проверяет непустые изображения стартовой иллюстрации и двух графиков; тест интерфейса также проверяет обновление траектории, поворот, язык и чёрно-белую схему в резервном режиме.

Нужны проверки сглаженных краёв, кириллицы, пунктира чёрно-белой схемы, постоянного изображения Canvas без очистки между кадрами и сохранения исходной траектории. Субъективную плавность движения нужно оценивать на последовательности кадров, а не по одному скриншоту. Отдельно проверяются стартовый пустой участок временного окна и движение абсолютных делений без растяжения старых данных.

## Интерфейс

Tkinter требует графический сеанс. Пропуск тестов интерфейса из-за отсутствия дисплея не подтверждает исправность окна.

Linux с виртуальным экраном:

```sh
STOCHLAB_GUI_TESTS=1 xvfb-run -a python -m unittest discover -s tests -v
```

Windows PowerShell:

```powershell
$env:STOCHLAB_GUI_TESTS = "1"
python -m unittest discover -s tests -v
```

Проверяются прокрутка панели без смещения графиков, колёсико над нужной областью, клавиатурная навигация, старт/пауза/стоп, поворот, палитры, RU/EN, авторы и маленькое окно. На обоих языках дополнительно проверяются постоянные навигационные кнопки, стабильные размеры графиков, TODO и отсутствие экспортных кнопок и удалённых пояснений.

## Упакованное приложение

```sh
python -m pip install -r requirements-build.txt
python -m PyInstaller --clean --noconfirm stochastic_resonance.spec
```

CI создаёт папки для Windows и Ubuntu 22.04. `--smoke-test` проверяет включённые ресурсы и зависимости без окна; `--smoke-test-gui` проверяет стартовую иллюстрацию и оба графика через мост Pillow—Tk, включая количество непустых пикселей в показанном PhotoImage. В готовую сборку должны войти aggdraw, Pillow, логотип и шрифт. Пользователь готовой сборки не устанавливает эти зависимости отдельно.

После полной распаковки артефакта нужно проверить окно, прокрутку, кириллицу, логотип, все палитры, поворот и движение графиков. На Linux исполняемому файлу может потребоваться `chmod +x`.

Проверьте запуск на компьютере преподавателя без установки Python, читаемость жирных заголовков и численных делений, доступность нижних настроек прокруткой, стабильность расположения при RU/EN и различимость линий чёрно-белого режима. Проверка в облачной среде не заменяет показ на проекторе.
