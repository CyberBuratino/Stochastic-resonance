# Стохастический резонанс / Stochastic Resonance Lab

Учебная демонстрация по статистической физике и термодинамике, написанная на **Python**. Частица взаимодействует с термостатом и движется в изменяемом двухъямном потенциале. Программа показывает частицу, мгновенный потенциал и графики координаты и периодической силы.

**Авторы:** Капитонов Станислав, Корж Евгения — ВМК МГУ.

**Лектор:** Григорьев Кирилл Сергеевич.

**Руководитель:** Чичигина Ольга Александровна.

## Запуск готового приложения

В GitHub откройте **Actions → Python application**, выберите успешную сборку нужной ветки или pull request и скачайте артефакт для своей системы:

- `StochasticResonance-Windows` — Windows, запуск `StochasticResonance.exe`;
- `StochasticResonance-Linux` — Linux, запуск `StochasticResonance`.

**Полностью распакуйте архив и сохраните папку `_internal` рядом с исполняемым файлом.** Готовое приложение включает Python, Tk и необходимые файлы. Для него не нужно устанавливать Python, библиотеки или запускать сервер. Интернет во время демонстрации не нужен. На Linux после распаковки при необходимости выполните `chmod +x StochasticResonance`.

Для компьютера защиты без Python скачайте **StochasticResonance-Windows** из успешного запуска Actions для нужного PR или ветки `main`. В распакованной папке дважды щёлкните **StochasticResonance.exe**. BAT-файл для этого не используется. Переносите всю папку приложения, включая `_internal`, а не только `.exe`.

Артефакты появляются только после успешного выполнения сборки GitHub Actions; это не файлы из кнопки **Code → Download ZIP**. Архив исходников предназначен для изучения и изменения программы. Linux-сборка создаётся на Ubuntu 22.04; совместимость с более старыми дистрибутивами не гарантируется. Проверку на компьютере преподавателя и проекторе нужно провести отдельно.

## Запуск исходников

Нужен Python 3.11 или новее с Tkinter. Для отрисовки графиков используются Pillow 12.0.0 и aggdraw 1.3.19; установите зависимости перед запуском исходников:

```sh
python -m pip install -r requirements.txt
python main.py
```

Windows: можно воспользоваться `start-windows.bat`; Linux: `sh start-linux.sh`. В Windows Tkinter устанавливается вместе с обычным Python с python.org при включённом компоненте Tcl/Tk. В Linux Tkinter иногда устанавливается отдельным пакетом, например `sudo apt install python3-tk`. Это требование относится к запуску исходников, а не готовой сборки.

Если при обновлении исходников aggdraw ещё не установлен или его нативная библиотека не загружается, приложение автоматически рисует через Pillow со сглаживанием. Эмблемы на главной странице и графики продолжают работать; интернет для переключения не нужен. Для основного растеризатора AGG установите зависимости из `requirements.txt`. В Windows используйте `py -3 -m pip install -r requirements.txt`, чтобы установить их в тот Python, который запускает `start-windows.bat`.

## Управление

На странице демонстрации **панель параметров прокручивается отдельно от графиков**. Колесо мыши над панелью или её вертикальная полоса прокрутки открывают нижние настройки. Область с частицей и двумя графиками остаётся на месте.

При открытии приложения показывается титульный экран: эмблема физфака слева, эмблема ВМК справа, между ними — полное название МГУ и факультета. Курс, название проекта и кнопки меню выровнены по центру. На странице авторов — две равные карточки с фотографиями, именами авторов, лектором и руководителем. На титульной странице верхняя панель скрыта, а RU/EN находится под кнопкой «Выход». В остальных разделах сохранена верхняя навигация и смена языка. При переходе в «Демонстрацию» расчёт начинается автоматически; исходный темп — ×1. Возвращение в раздел продолжает текущую реализацию без сброса; вручную выбранный темп сохраняется. Кнопки «Старт», «Пауза», «Стоп» и «Режим резонанса» закреплены над прокручиваемыми параметрами. Надписи меню и кнопок увеличены до 16 pt, обычный текст — до 14 pt. Числа в полях, выбранные значения и пункты выпадающих меню отображаются шрифтом 16 pt, деления графиков — 18 px. Переключатель периодической силы тоже остаётся крупным. Названия параметров показаны шрифтом 16 pt. Температурные кнопки размещены по одной в строке, чтобы крупный текст помещался.

В верхней части окна расположены постоянные переходы «Главная» и «Демонстрация» и переключатель RU/EN. Смена языка не перестраивает размеры области графиков. Можно менять температуру T, параметры «Барьер» и «Глубина ям», амплитуду f, частоту ω и трение γ. Буквы a и b в подписях демонстрации не показываются. Поле зерна генератора убрано; внутреннее зерно сохраняется для воспроизводимости. Изменение физического параметра начинает новую реализацию. Старт продолжает расчёт, пауза сохраняет состояние, стоп сбрасывает траекторию. Быстрый темп меняет число шагов за секунду показа, а не шаг интегрирования. Поворот графика переключает вертикальную и горизонтальную ось времени.

Меню оформления предлагает разные принципы окраски:

- **По величинам:** координата и потенциал одного цвета, внешняя сила — другого.
- **По сторонам барьера:** участки траектории различаются по нахождению слева или справа; отдельные надписи x < 0 / x ≥ 0 убраны.
- **Чёрно-белая:** монохромные линии, различение координаты и силы с помощью сплошного и пунктирного начертания.

Цветовая схема изменяет только отображение, не состояние частицы и не результаты расчёта. В текущем интерфейсе нет сохранения CSV или SVG и нет расчёта кривой отклика по температурам. Страница теории содержит только `TODO` на обоих языках. Справочное описание модели и источники остаются ниже в README.

Кнопка «Режим резонанса» восстанавливает весь набор: a=1, b=0,5, T=0,35, f=0,24, ω=0,08, γ=1, Δt=0,02, сила включена, внутреннее зерно 42, обычный темп показа ×1. Она начинает реализацию заново даже после некорректного ввода или ошибки расчёта. Цвет и поворот сохраняются. Это показательный режим согласованных с силой тепловых переходов, а не утверждение об универсальном максимуме резонанса. Кнопка «Средняя T» задаёт температуру этого примера, но остальные параметры не меняет.

Поля «Барьер» и «Глубина ям» управляют прежними коэффициентами a и b исходной формулы. Показанные в полях числа не являются измеренными высотой и глубиной; названия поясняют роль настроек, а математические обозначения оставлены в этом описании модели. Для a,b>0 высота барьера над дном ямы и глубина ямы относительно U(0)=0 равны одной величине ΔU=a²/(4b). При фиксированном b увеличение a повышает барьер; при фиксированном a увеличение b уменьшает глубину и расстояние между минимумами ±√(a/b).

Силу можно выключить отдельным переключателем, сохранив амплитуду, или поставить f=0. При a=0, b>0 остаётся одна яма; при a=b=0 — плоский потенциал. Для плоского случая сначала установите a=0. Комбинация a>0, b=0 запрещена: потенциал не ограничен снизу.

## Отображение графиков

Частица движется по дорожке под графиком потенциала, у общей границы двух рисунков. В вертикальном положении траектории её текущий конец расположен прямо под частицей: они используют одну шкалу координаты x и соединены коротким вертикальным пунктиром. Текущий конец траектории выделен маркером. После поворота маркер сохраняется, но соединительный вертикальный пунктир отключается, поскольку ось x траектории становится осью времени.

Заголовок «Траектория и внешняя сила» и кнопка поворота находятся сбоку, в закреплённой панели. Между рисунками нет отдельной строки заголовка: освободившееся место занимает траектория.

Стационарный потенциал U(x), без периодической силы, показан нейтральным пунктиром. Мгновенный потенциал Ueff(x,t)=U(x)−xF(t) показан сплошной линией. Обе кривые используют одни и те же оси; при выключенной силе, нулевой амплитуде или F(t)=0 они совпадают. Пунктирная опора не влияет на расчёт частицы.

Линии рисуются векторным растеризатором AGG через aggdraw с покрытием пикселей непосредственно в экранном разрешении. Pillow хранит готовый кадр и передаёт его Tkinter. В основном режиме нет уменьшения увеличенного изображения и фильтра Lanczos. Если aggdraw недоступен, Pillow рисует в разрешении не менее 4× и уменьшает кадр фильтром Lanczos. Новый кадр заменяет старый без предварительной очистки Canvas. Оба способа сохраняют исходные точки и геометрию графиков.

`GRAPH_SUPERSAMPLING` в `appearance.py` по умолчанию равен 1. Это необязательная настройка масштаба вспомогательного изображения, а не способ фильтрации данных. Локальный шрифт с кириллицей включён в проект и готовые сборки. Пользователю готового приложения не нужно устанавливать Pillow, aggdraw или шрифт.

Меню «Окно нижнего графика» позволяет выбрать 3 или 6 периодов силы; при запуске выбраны 3. История последних 6 периодов сохраняется постоянно, поэтому расширить окно можно сразу и на паузе, без сброса параметров и траектории. После запуска или сброса ещё не рассчитанная часть окна остаётся пустой: вымышленных точек нет. При выключенной силе длительность по-прежнему определяется сохранённой частотой ω.

При выбранной длине окна масштаб времени не растягивается по мере накопления данных; деления привязаны к абсолютному времени и смещаются вместе с окном. Траектория строится по сохранённым точкам без сглаживания координаты и скрытого удаления её колебаний. Известная периодическая сила рассчитывается по формуле в доступном интервале времени. Окно в 6 периодов содержит больше точек и может снижать плавность на слабом компьютере; можно вернуться к 3 без перезапуска расчёта.

Оси подписаны кратко: `x`, `t`, `Ueff`, `F`. Значки единиц `[1]` и поясняющие строки под графиком убраны; все величины по-прежнему безразмерные. Заголовки выделены жирным. Масштабы координаты и энергии во время реализации только расширяются при выходе данных за границы; сбрасываются кнопкой «Стоп» или изменением параметров.

## Физическая модель

```text
U(x) = −a x²/2 + b x⁴/4
 dx = v dt
 dv = [a x − b x³ − γv + F(t)] dt + √(2γT) dW
F(t) = f sin(ωt), если сила включена, иначе 0
D = γT;  ⟨ξ(t)ξ(t′)⟩ = 2γT δ(t−t′)
```

Величины безразмерные, масса и постоянная Больцмана равны единице. T — приведённая температура, не кельвины; в размерной записи D=γkBT. В равновесии ⟨v²⟩=T. При a,b>0 минимумы находятся в ±√(a/b), барьер ΔU=a²/(4b). На графике сплошной линией показан мгновенный потенциал Ueff(x,t)=U(x)−xF(t), пунктиром — стационарный U(x).

Динамика рассчитывается методом BAOAB с Δt=0,02. Шаг Орнштейна—Уленбека учитывает трение и тепловые толчки: `v ← exp(−γΔt)v + sqrt(T·(1−exp(−2γΔt)))·N(0,1)`. Зерно задаёт воспроизводимую последовательность случайных чисел. Пороговые значения ±½√(a/b) исключают лишний подсчёт быстрых повторных пересечений вершины барьера.

## Проверка и сборка

Проверки запускаются стандартным модулем Python:

```sh
python -m unittest discover -s tests -v
```

Для проверки интерфейса нужен графический сеанс. На Linux без экрана можно использовать `xvfb-run`; инструкция и ограничения находятся в [docs/VALIDATION.md](docs/VALIDATION.md).

Собрать исполняемую папку для текущей ОС:

```sh
python -m pip install -r requirements-build.txt
python -m PyInstaller --clean --noconfirm stochastic_resonance.spec
```

Результат — `dist/StochasticResonance/`. Для Windows сборку нужно выполнять на Windows, для Linux — на Linux. PyInstaller нужен только разработчику во время упаковки. Файл `requirements-build.txt` фиксирует версию упаковщика; приложение не импортирует его при работе.

GitHub Actions выполняет тесты, включая запуск исходников без aggdraw, и собирает обе версии. `--smoke-test` проверяет ресурсы, а `--smoke-test-gui` проверяет титульную страницу, эмблемы, карточки авторов с фотографиями и меню языка на титульной странице и оба графика. Состояние фактических проверок следует смотреть в соответствующем запуске Actions и [docs/VALIDATION.md](docs/VALIDATION.md).

## English quick start

Download a successful GitHub Actions artifact for Windows or Linux, extract the **entire folder**, and run `StochasticResonance.exe` or `StochasticResonance`. The packaged app includes Python and Tk and works offline; the BAT launcher is not required. For source editing, use Python 3.11+ with Tkinter, install `python -m pip install -r requirements.txt`, then run `python main.py`. The app opens on a centered academic title page with Physics and CMC emblems, the university and faculty names, course and project title. The Authors page has two matching photo cards, author names, lecturer and supervisor. The home screen hides the top panel and places its language button below Exit; the other pages keep the navigation bar and language switch. Entering Demonstration automatically starts the simulation at the default 1× speed; returning preserves the current trajectory and any manually selected speed. Large Start/Pause/Stop buttons and a Resonance preset button stay above the independently scrolling parameters. The preset restores all simulation settings and restarts a reproducible example; the random seed field is hidden. Parameter names use 16 pt type; the two potential controls are named Barrier and Well depth, with the a/b symbols omitted from the demonstration. The trajectory caption and Rotate button are in the fixed sidebar. The particle sits below the potential, close to the current trajectory endpoint; the vertical view uses a short dashed connector, while the rotated view keeps only the endpoint marker. The stationary potential is a neutral dashed reference behind the solid instantaneous potential. Choose quantity-based, state-based or monochrome colors; the state palette has no side-legend text. CSV/SVG export is removed; the Theory page displays only TODO. Graph axes are x, t, Ueff and F. Choose a three- or six-period time window (three by default); the last six periods remain available even while paused. Switching windows preserves the simulation and history, with blank prehistory at startup. Visual settings are in `stochlab/appearance.py`, the preset is in `stochlab/presets.py`, and the physical model is separate in `stochlab/model.py`.
