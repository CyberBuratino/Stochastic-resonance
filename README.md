# Стохастический резонанс / Stochastic Resonance Lab

Учебная демонстрация по статистической физике и термодинамике, написанная на **Python**. Частица взаимодействует с термостатом и движется в изменяемом двухъямном потенциале. Программа показывает частицу, мгновенный потенциал и графики координаты и периодической силы.

**Авторы:** Капитонов Станислав, Корж Евгения — ВМК МГУ.

**Преподаватель:** Чичигина Ольга Александровна.

## Запуск готового приложения

В GitHub откройте **Actions → Python application**, выберите успешную сборку нужной ветки или pull request и скачайте артефакт для своей системы:

- `StochasticResonance-Windows` — Windows, запуск `StochasticResonance.exe`;
- `StochasticResonance-Linux` — Linux, запуск `StochasticResonance`.

**Полностью распакуйте архив и сохраните папку `_internal` рядом с исполняемым файлом.** Готовое приложение включает Python, Tk и необходимые файлы. Для него не нужно устанавливать Python, библиотеки или запускать сервер. Интернет во время демонстрации не нужен. На Linux после распаковки при необходимости выполните `chmod +x StochasticResonance`.

Артефакты появляются только после успешного выполнения сборки GitHub Actions; это не файлы из кнопки **Code → Download ZIP**. Архив исходников предназначен для изучения и изменения программы. Linux-сборка создаётся на Ubuntu 22.04; совместимость с более старыми дистрибутивами не гарантируется. Проверку на компьютере преподавателя и проекторе нужно провести отдельно.

## Запуск исходников

Нужен Python 3.11 или новее с Tkinter. Для сглаживания графиков используется Pillow; установите зависимость перед запуском исходников:

```sh
python -m pip install -r requirements.txt
python main.py
```

Windows: можно воспользоваться `start-windows.bat`; Linux: `sh start-linux.sh`. В Windows Tkinter устанавливается вместе с обычным Python с python.org при включённом компоненте Tcl/Tk. В Linux Tkinter иногда устанавливается отдельным пакетом, например `sudo apt install python3-tk`. Это требование относится к запуску исходников, а не готовой сборки.

## Управление

На странице демонстрации **панель параметров прокручивается отдельно от графиков**. Колесо мыши над панелью или её вертикальная полоса прокрутки открывают нижние настройки. Область с частицей и двумя графиками остаётся на месте.

Можно менять температуру T, коэффициенты потенциала a/b, амплитуду f, частоту ω, трение γ и зерно генератора. Изменение физического параметра начинает новую реализацию. Старт продолжает расчёт, пауза сохраняет состояние, стоп сбрасывает траекторию. Быстрый темп меняет число шагов за секунду показа, а не шаг интегрирования. Поворот графика переключает вертикальную и горизонтальную ось времени.

Меню оформления предлагает разные принципы окраски:

- **По величинам:** координата и потенциал одного цвета, внешняя сила — другого.
- **По сторонам барьера:** участки траектории различаются по нахождению слева или справа.
- **Чёрно-белая:** монохромные линии, различение координаты и силы с помощью сплошного и пунктирного начертания.

Цветовая схема изменяет только отображение, не состояние частицы и не результаты расчёта. SVG-экспорт сохраняет текущие графики в векторном виде с выбранной окраской; чёрно-белая схема удобна для печати и вставки в отчёт. CSV-экспорт содержит видимую траекторию и параметры расчёта. Отдельного расчёта кривой отклика по температурам нет.

Исходные настройки: a=1, b=0,5, T=0,22, f=0,18, ω=0,04, γ=1, seed=42. Силу можно выключить отдельным переключателем, сохранив амплитуду, или поставить f=0. При a=0, b>0 остаётся одна яма; при a=b=0 — плоский потенциал. Для плоского случая сначала установите a=0. Комбинация a>0, b=0 запрещена: потенциал не ограничен снизу.

## Качество графиков

Экранные графики рисуются в увеличенном разрешении и уменьшаются фильтром Lanczos. Целый кадр заменяет предыдущий без очистки Canvas. Это сглаживает края линий и надписей, а не физические колебания частицы. Все сохранённые точки траектории остаются на графике; известная периодическая сила строится независимо по формуле. Масштаб координаты и энергии во время реализации только расширяется, если данные выходят за границы, и сбрасывается кнопкой «Стоп» или изменением параметров.

В `appearance.py` параметр `GRAPH_SUPERSAMPLING` задаёт качество: 2 — стандартное сглаживание с умеренной нагрузкой; 3 повышает качество ценой времени отрисовки. SVG остаётся векторным. Шрифт с кириллицей включён в проект и готовые сборки. Пользователю готового приложения не нужно устанавливать Pillow или шрифт.

## Физическая модель

```text
U(x) = −a x²/2 + b x⁴/4
 dx = v dt
 dv = [a x − b x³ − γv + F(t)] dt + √(2γT) dW
F(t) = f sin(ωt), если сила включена, иначе 0
D = γT;  ⟨ξ(t)ξ(t′)⟩ = 2γT δ(t−t′)
```

Величины безразмерные, масса и постоянная Больцмана равны единице. T — приведённая температура, не кельвины; в размерной записи D=γkBT. В равновесии ⟨v²⟩=T. При a,b>0 минимумы находятся в ±√(a/b), барьер ΔU=a²/(4b). На графике показан мгновенный потенциал Ueff(x,t)=U(x)−xF(t).

Динамика рассчитывается методом BAOAB с Δt=0,02. Шаг Орнштейна—Уленбека учитывает трение и тепловые толчки: `v ← exp(−γΔt)v + sqrt(T·(1−exp(−2γΔt)))·N(0,1)`. Зерно задаёт воспроизводимую последовательность случайных чисел. Пороговые значения ±½√(a/b) исключают лишний подсчёт быстрых повторных пересечений вершины барьера.

## Проверка и сборка

Проверки запускаются стандартным модулем Python:

```sh
python -m unittest discover -s tests -v
```

Для проверки интерфейса нужен графический сеанс. На Linux без экрана можно использовать `xvfb-run`; инструкция и ограничения находятся в [docs/VALIDATION.md](docs/VALIDATION.md).

Собрать исполняемую папку для текущей ОС:

```sh
python -m pip install -r requirements-build.txt
python -m PyInstaller --clean --noconfirm stochastic_resonance.spec
```

Результат — `dist/StochasticResonance/`. Для Windows сборку нужно выполнять на Windows, для Linux — на Linux. PyInstaller нужен только разработчику во время упаковки. Файл `requirements-build.txt` фиксирует версию упаковщика; приложение не импортирует его при работе.

GitHub Actions выполняет тесты, собирает обе версии и проверяет запуск упакованного приложения с `--smoke-test` и открытие обоих графиков с `--smoke-test-gui`. Состояние фактических проверок следует смотреть в соответствующем запуске Actions и [docs/VALIDATION.md](docs/VALIDATION.md).

## English quick start

Download a successful GitHub Actions artifact for Windows or Linux, extract the **entire folder**, and run `StochasticResonance.exe` or `StochasticResonance`. The packaged app includes Python and Tk and works offline. For source editing, use Python 3.11+ with Tkinter, install `python -m pip install -r requirements.txt`, then run `python main.py`. The parameter sidebar scrolls independently, while the plots remain visible. Choose quantity-based, state-based or monochrome colors; export SVG for citation and CSV for trajectory data. Visual settings are in `stochlab/appearance.py`; the physical model is separate in `stochlab/model.py`.
