# Стохастический резонанс / Stochastic Resonance Lab

Автономная RU/EN демонстрация по статистической физике и термодинамике. Частица взаимодействует с термостатом и движется в изменяемом двухъямном потенциале. Приложение показывает движение и численно измеряет периодический отклик при разных температурах.

**Авторы:** Капитонов Станислав, Корж Евгения — ВМК МГУ.

**Преподаватель:** Чичигина Ольга Александровна.

## Запуск

Скачайте репозиторий (**Code → Download ZIP**), распакуйте полностью и откройте `index.html` в современном Edge, Chrome, Firefox или Chromium. Windows: также `start-windows.bat`; Linux: `sh start-linux.sh` (системный `xdg-open`). F11 — полный экран.

Интернет, сервер, Python, Node.js и установка библиотек для приложения не нужны. Все изображения и формулы локальные; математическая вёрстка — встроенный MathML. Internet Explorer и старые браузеры без поддержки MathML не поддерживаются. Отдельный EXE не поставляется.

## Что изменено во второй версии

- Стартовый экран: только название, переходы к демонстрации/теории/авторам, язык и рисунок потенциала без подписей.
- Коэффициенты a и b изменяют форму потенциала; рассчитываются положения минимумов, барьер и порог исчезновения ямы.
- Частица движется по горизонтальной прямой над потенциалом; пунктир показывает проекцию.
- Кнопка поворачивает график траектории **и силы** на 90° без сброса состояния. По умолчанию время направлено вверх; шкала x совпадает с потенциалом. У силы отдельная верхняя шкала. В горизонтальном режиме у силы правая шкала.
- Управление температурой T вместо независимой интенсивности шума: D = γT.
- Отдельный выключатель периодической силы сохраняет амплитуду f. Ранее воздействие можно было убрать только значением f = 0; этот способ тоже сохранён.
- Обновлённые сведения об авторах, локальный логотип ВМК и раздел теории с дробями, корнями и индексами в MathML.

## Управление

Температура T, коэффициенты a/b, амплитуда f, частота ω, трение γ и зерно генератора. Изменение физического параметра начинает новую реализацию и очищает измерение; поворот графика и язык данные сохраняют. Старт продолжает, пауза сохраняет состояние, стоп сбрасывает анимацию. Медленный/быстрый режим меняет число шагов за секунду, но не шаг интегрирования.

По умолчанию a=1, b=0,5, T=0,22, f=0,18, ω=0,04, γ=1, seed=42. Низкая/средняя/высокая T — пресеты температуры. При a=0, b>0 остаётся одна яма; при a=b=0 — плоский потенциал. Чтобы сделать его плоским, сначала установите a=0. Комбинация a>0, b=0 запрещена как неограниченный снизу потенциал.

Измерение использует 12 температур × 6 реализаций, 4 периода разогрева и 16 периодов измерения. Его можно отменить отдельно от анимации. Оно недоступно при выключенной силе, f=0 или отсутствии двух ям. Если сила достигает порога исчезновения барьера, интерфейс сообщает об этом: возможны переходы без помощи шума.

CSV траектории содержит последние 3 периода и параметры. CSV отклика содержит завершённые точки, температуру T, соответствующую интенсивность D и стандартные ошибки. Это амплитуда среднего отклика, **не SNR**. Максимум на конечной сетке не определяет точный оптимум.

## Модель

```text
U(x) = -a x²/2 + b x⁴/4
 dx = v dt
 dv = [a x - b x³ - γv + F(t)] dt + √(2γT) dW
F(t) = f sin(ωt) при включённой силе, иначе 0
D = γT;  ⟨ξ(t)ξ(t′)⟩ = 2γT δ(t-t′)
```

Все величины безразмерные; масса и постоянная Больцмана равны единице. T — приведённая температура, не кельвины. В размерной записи D=γkBT. Равновесная кинетическая температура ⟨v²⟩=T не зависит от γ.

При a,b>0: минимумы ±√(a/b), барьер ΔU=a²/(4b), статический порог силы fc=(2a/3)√(a/(3b)). На экране Ueff=U−xF(t). Исходный потенциал из конспекта соответствует a=1, b=0,5. Пересечения считаются с гистерезисом ±½√(a/b); при a=0 межъямные переходы не определены.

Интегратор BAOAB, Δt=0,02. Точный OU-шаг: `v ← exp(-γΔt)v + sqrt(T*(1-exp(-2γΔt)))*N(0,1)`. PRNG Mulberry32 и преобразование Box–Muller. Измерение вычисляет S=2⟨x sin(ωt)⟩, C=2⟨x cos(ωt)⟩ в каждой реализации, затем A=hypot(mean(S),mean(C)). Ошибка оценивается дельта-методом; около нулевого A она приближённая.

## Проверки

Разработчику нужен Node.js ≥20, без npm-зависимостей для физических тестов:

```sh
npm test
```

13 тестов проверяют исходную модель, новую геометрию, температурную нормировку, выключатель силы, плоский потенциал и крайние параметры. CI запускается при push/PR.

Дополнительный тест интерфейса: Playwright и установленный Chromium; `node tests/browser.cjs`, при необходимости `CHROMIUM_PATH`. Скриншоты — в системном временном каталоге. Тест по умолчанию использует file://. В облачном Chromium этот протокол запрещён административной политикой, поэтому проверка проведена через временный сервер с `TEST_URL=http://127.0.0.1:8765/index.html`. Прямой запуск файла и Windows остаются приёмочными проверками.

Код: `js/physics.js` — модель, `js/app.js` — управление/графики, `js/theory.js` — теория/MathML, `index.html` — страницы, `style.css` — оформление. Детали: [требования](docs/REQUIREMENTS.md), [валидация](docs/VALIDATION.md).

Перед сдачей нужны настоящие фотографии авторов и проверка на компьютере преподавателя с проектором.

## English quick start

Extract the complete repository and open `index.html` in a modern browser. Select EN → Demonstration → Start. The app works offline without installing libraries. Adjust a/b to change the potential and T to change the bath temperature (D=γT). Toggle the periodic force or rotate both traces without losing data. Native MathML renders the theory. The sweep measures the ensemble-mean response amplitude, not SNR. Check Windows/file:// and classroom hardware before final acceptance.
