# Стохастический резонанс / Stochastic Resonance Lab

Автономная интерактивная презентация по статистической физике. Частица с инерцией движется в двухъямном потенциале под действием периодической силы, трения и белого шума. Приложение показывает траекторию и **численно измеряет** зависимость периодического отклика от интенсивности шума.

**Авторы:** Капитонов Станислав, Корж Евгения — ВМК МГУ.

**Преподаватель-руководитель:** Чичигина Ольга Александровна.

## Запуск за минуту

1. Скачайте репозиторий через **Code → Download ZIP** и полностью распакуйте архив.
2. Откройте `index.html` в современном Edge, Chrome, Firefox или Chromium.
3. Выберите «Презентация» → «Старт».

Windows: можно дважды щёлкнуть `start-windows.bat`. Linux: открыть `index.html` либо выполнить `sh start-linux.sh` (использует системный `xdg-open`). Пути с пробелами поддерживаются. Все файлы должны оставаться в одной папке с исходной структурой.

**Не нужны** интернет, сервер, Python, Node.js, npm или установка библиотек. Нет CDN, сетевых шрифтов, аналитики или сетевых запросов приложения. Для компьютера преподавателя достаточно современного браузера. Старые версии Windows и Internet Explorer не поддерживаются; отдельный EXE не поставляется. Полноэкранный режим браузера: F11.

## Возможности

- Русский и английский интерфейс, включая теорию и сообщения состояния.
- Титульная страница, презентация, теория, авторы и выход (останавливает расчёт; вкладку закрывает пользователь).
- Анимация частицы в мгновенном потенциале, синхронный график координаты и силы с раздельными шкалами.
- Изменение шума D, силы f, частоты ω, трения γ; воспроизводимые реализации по зерну генератора.
- Старт, пауза, стоп, медленный и быстрый темп. Быстрый темп не меняет шаг интегрирования.
- Измерение отклика: 12 уровней шума, 6 реализаций на уровень, 4 периода разогрева и 16 периодов измерения. Расчёт можно отменить.
- Амплитуда среднего отклика и стандартная ошибка, CSV траектории и результатов с параметрами расчёта.
- Адаптация к размеру окна, численные деления и обозначения безразмерных осей `[1]`.

При изменении физических параметров расчёт начинается заново и очищает предыдущую кривую отклика. CSV траектории содержит видимое окно (последние 3 периода), а не бесконечную историю. CSV измерения содержит завершённые точки, в том числе при отмене. Пауза и стоп относятся к анимации; у измерения отдельная кнопка отмены. При уходе с презентации анимация ставится на паузу, измерение может продолжаться.

## Физическая модель

Основа: О. А. Чичигина, «Флуктуационные процессы», §12.6, с. 103–105. Модель со скриншота задания сохраняет инерцию:

```text
V(x) = -x²/2 + x⁴/8
 dx = v dt
 dv = [x - x³/2 - γv + f sin(ωt)] dt + √(2D) dW
⟨ξ(t)ξ(t′)⟩ = 2D δ(t−t′)
```

Масса равна единице, все величины безразмерные. Минимумы ±√2, барьер 1/2. D — интенсивность случайной силы; эффективная температура в равновесии D/γ. На экране U(x,t) = V(x) − fx sin(ωt). Диапазон f ≤ 0,5 сохраняет две мгновенные ямы, но не исключает динамические переходы без шума.

Интегратор **BAOAB**, Δt = 0,02. Точный OU-шаг скорости: `v ← exp(-γΔt) v + sqrt((D/γ)(1-exp(-2γΔt))) N(0,1)`. Воспроизводимый PRNG Mulberry32, нормальные величины через Box–Muller. Межъямные переходы считаются с гистерезисом ±0,7.

Измеряется амплитуда среднего комплексного отклика на частоте ω, **не SNR**. В каждой реализации после разогрева вычисляются `a=2⟨x sin(ωt)⟩`, `b=2⟨x cos(ωt)⟩`; затем `A=hypot(mean(a),mean(b))`. Стандартная ошибка оценивается дельта-методом по реализациям. Это приближённая оценка при малом A. Кривая строится из траекторий, не из заранее заданной функции. Конечное число реализаций и точек D ограничивает точность положения максимума; для произвольных настроек максимум не гарантирован.

## Демонстрация на занятии

1. Стандартные параметры: f=0,18, ω=0,04, γ=1, seed=42.
2. Слабый шум: движение преимущественно в одной яме.
3. Умеренный шум и быстрый темп: наблюдать переходы между ямами и их связь с силой.
4. Сильный шум: переходы становятся менее упорядоченными.
5. Нажать «Измерить резонанс» и дождаться всех 72 реализаций. Время расчёта зависит от компьютера.
6. Объяснить максимум отклика, погрешность и ориентир τ ~ π/ω; сохранить CSV.

## Проверка и разработка

Только разработчику нужен Node.js ≥20. Зависимостей для физических тестов нет:

```sh
npm test
```

Проверяются потенциал и сила, ограничения параметров, воспроизводимость, статистика шума, неподвижное равновесие без шума, равновесная температура D/γ, сравнение шагов 0,02 и 0,01, максимум отклика и устойчивость крайних параметров. CI выполняет эти проверки при push и pull request.

Дополнительный браузерный тест: установить Playwright в среду разработки (`npm install --no-save playwright`), установить Chromium и выполнить `node tests/browser.cjs`. При необходимости указать `CHROMIUM_PATH`. Тест использует `file://`, проверяет управление, языки, отмену и полный расчёт, CSV, мобильную ширину, отсутствие сетевых запросов и ошибок JavaScript. Скриншоты сохраняются в системный временный каталог. В облачной среде file:// запрещён политикой Chromium: фактически браузерный тест выполняется через локальный сервер с `TEST_URL=http://127.0.0.1:8765/index.html`; прямой запуск файла остаётся отдельной приёмочной проверкой.

Структура: `index.html` — страницы; `style.css` — оформление; `js/physics.js` — модель; `js/app.js` — управление, графики и локализация; `tests/` — проверки; `docs/` — требования и результаты валидации.

## English quick start

Download and extract the entire repository, open `index.html` in a modern browser, click **EN**, then **Presentation → Start**. Works offline on Windows/Linux without installing libraries or a server. The inertial Langevin simulation uses BAOAB and seeded Gaussian noise. The noise sweep measures the amplitude of the ensemble-mean periodic response with standard errors. CSV exports include model parameters. This is a response-amplitude experiment, not an SNR measurement. Author photos and the official faculty emblem remain to be supplied; classroom hardware acceptance is still required.
